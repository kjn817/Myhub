> 사용법: 브라우저 QA를 수행할 때마다 이 파일을 복사해
> `docs/qa-browser-YYYYMMDD-HHMM.md` 로 저장하고 항목을 채운다.
> 이 템플릿 원본은 항상 비워둔다. 한 번에 하나씩, 꼼꼼히.

## 5. 보안·보호 항목

### MEMO-001 (잠금 버튼 비활성화)
- [ ] 잠금 버튼 DOM: `disabled`, `opacity: 0.5`, `cursor: not-allowed`
- [ ] 클릭 시 무동작 (브라우저가 disabled로 거부)

### SEC-001 (비신뢰 HTML 실행 차단)
- 아래 페이로드를 채팅 `renderMarkdown`에 통과시켜 실행 차단 확인.
  콘솔에서 직접 실행해도 되고, 테스트 메시지로 전송해도 된다
  (전송 시 AI 호출이 발생하면 비용 유의 — 콘솔 직접 실행 권장).

| 페이로드 | 출력에 핸들러 잔존? | 삽입 시 실행? | 판정 |
|----------|---------------------|---------------|------|
| `<script>alert(1)</script>` | | | |
| `<img src=x onerror="window.__x1=1">` | | | |
| `<svg onload="window.__x2=1">` | | | |
| `<a href="javascript:window.__x3=1">x</a>` | | | |
| `<div onmouseover="window.__x4=1">x</div>` | | | |

- 판정 기준: 5종 모두 핸들러 제거 + 플래그 미설정이어야 PASS.

### 주의사항
- 기존 사용자 데이터(메모/할 일/일정/채팅/AI 기록)는 절대 수정·삭제하지 않는다.
- 브라우저 환경이 중단(retired)되면: 했던 작업의 실제 반영 여부를 먼저 확인하고
  중복 실행하지 않는다. 네이티브 alert/dialog가 렌더러를 막을 수 있다.
- 테스트 중 생성한 데이터는 반드시 정리한다.

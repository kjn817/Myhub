# 할 일 50가지 상세 QA 케이스 (49차)

## 생성 (1-15)
1. 기본 할 일 생성
2. 빈 제목으로 생성
3. 공백만 입력
4. 매우 긴 제목 (200자)
5. 한글 입력
6. 영어 입력
7. 이모지 입력 ✅🎯
8. 특수문자 !@#$%
9. HTML 태그 입력
10. 우선순위 설정 (높음)
11. 우선순위 설정 (낮음)
12. 마감일 설정 (오늘)
13. 마감일 설정 (내일)
14. 마감일 설정 (과거)
15. 연속 5회 빠른 생성

## 조회 (16-25)
16. 목록 표시
17. 진행중/완료 탭 전환
18. 우선순위별 정렬
19. 마감일별 정렬
20. 새로고침 후 상태 유지
21. 대량 할 일 (100개) 로딩
22. 빈 목록 표시
23. 오늘 마감 할 일 필터
24. 기한 지난 할 일 표시
25. 검색

## 완료 토글 (26-35)
26. 미완료 → 완료
27. 완료 → 미완료
28. 빠른 연속 토글 3회
29. 완료 후 카운트 변경
30. 여러 개 연속 완료
31. 존재하지 않는 ID 토글
32. 토글 후 새로고침 유지
33. 완료된 항목 수정
34. 완료된 항목 삭제
35. 전체 완료/해제

## 수정·삭제 (36-45)
36. 제목 수정
37. 마감일 수정
38. 우선순위 수정
39. 존재하지 않는 할 일 수정
40. 할 일 삭제
41. 삭제 확인
42. 존재하지 않는 할 일 삭제
43. 삭제 후 카운트 반영
44. 연속 삭제 3개
45. 수정 후 토글

## 순서·기타 (46-50)
46. 드래그 순서 변경
47. 순서 변경 후 새로고침 유지
48. 중복 클릭 방지
49. 네트워크 오류 시 동작
50. 세션 만료 후 동작

# E2B 무료 티어 조건 확인 (트랙 C9, 조사만 — 2026-10-26)

조사 기준일: 2026-10-26. 근거 문서: `docs/github-apply-research-20261026.md` 2-9절
(E2B ★14,557 · Apache-2.0). 코드 변경 없음. 운영 D1 쓰기·배포·라이브 호출 없음.

## 결론 (한 줄)

**카드 없이 POC는 가능하나, 운영 도입은 불가 — $100은 월 반복이 아닌 일회성 크레딧이라
소진되면 카드 등록 전까지 계정이 막히고, 이후 유료 전환(Pro $150/월)은
Cloudflare Sandbox($5/월)보다 비싸다.** E2B는 AI 스튜디오 미리보기 POC용으로만
유효하고, 장기 샌드박스가 필요해지면 Cloudflare Sandbox를 다시 평가하는 것이 싸다.

## 1. 무료 티어 조건 (공식 문서 기준)

출처: E2B 공식 가격 페이지 (`e2b.dev/pricing`, 2026-10-26 직접 확인) 및
공식 과금 문서 (`e2b.dev/docs/billing`, 최종 업데이트 2026-10-22).

| 항목 | Hobby (무료) | Pro | Enterprise |
| --- | --- | --- | --- |
| 기본 요금 | $0/월 | $150/월 + 사용량 | 맞춤 |
| 무료 크레딧 | **$100 일회성 (one-time)** | 추가 크레딧 없음 | 맞춤 |
| 세션 최대 길이 | 1시간 (pause/resume 시 리셋) | 24시간 | 맞춤 |
| 동시 샌드박스 | 20개 | 100개 (최대 1,100) | 수만 개 |
| CPU / RAM | 기본값만 (최대 8 vCPU / 8 GiB) | 커스텀 가능 | 맞춤 |
| 디스크 | 10 GiB | — | 맞춤 |

- **과금 방식**: 실행 중인 샌드박스만 초 단위 과금. 일시정지(pause)·종료(kill) 상태는 과금 없음.
  일시정지된 샌드박스는 무기한 보관 가능(TTL 없음), 실행 중일 때만 동시 실행 한도에 포함.
- **단가**: $0.0504/vCPU-hour + $0.0162/GiB-hour. 기본 샌드박스(2 vCPU, 1 GiB)는
  시간당 약 $0.117 → **$100 크레딧 ≈ 기본 샌드박스 약 855시간** (Vercel 공식 비교 문서의 계산과 일치).
- **GPU**: 없음. E2B 샌드박스는 CPU 전용 (공식 FAQ 명시, BYOC도 GPU 없음).
- **EU 클러스터**: 결제 수단으로 검증된 워크스페이스에만 제공 (공식 FAQ) — 기본 US 클러스터 사용 시 해당 없음.

### 1-1. 카드 등록 필요 여부 — 시작 시점: 불필요

- E2B 공식 가격·과금 문서에는 **Hobby 가입 시 카드 등록 요구가 명시돼 있지 않다.**
- 독립 2차 출처 4건이 일치하게 "no card required"로 기록:
  Prized 비교 문서 (`prized.dev/docs/sandboxes-vs-e2b-daytona-modal`, "$100 once, no card"),
  BetterStack 비교 문서 ("no credit card required"),
  Creati.ai ("Is credit card required: No"),
  TechStackups 비교 문서 ("$100 one-time credits, no card required").
- **판정: 카드 없이 계정 생성·API 키 발급·Hobby 사용 시작 가능.** 사용자 원칙(카드 등록·초과 과금 동의가
  필요한 무료 서비스 절대 불가)에 시작 단계에서는 저촉되지 않는다.

### 1-2. 크레딧 소진 시 — 자동 과금 아님, 사용 중단

- 카드가 등록돼 있지 않으므로 자동 과금은 구조적으로 불가능하다.
  2차 출처(buildaicurrent.com, 2026-08-20에 E2B 가격·과금 페이지 대조 확인)는
  E2B FAQ를 인용해 **"크레딧이 떨어지면 결제 수단을 추가할 때까지 계정이 차단된다
  (your account is blocked until you add a payment method)"**고 기록한다.
- 즉 초과 시 동작은 **사용 중단(차단)**, 자동 청구가 아니다. 과금 누수(모르는 새 과금) 위험은 없다.
- **검증 간극 (정직하게 기록)**: E2B 현행 공개 FAQ 페이지(`e2b.dev/docs/faq`,
  2026-10-22 업데이트)에는 크레딧 소진 시 동작을 묻는 항목이 **없다**.
  "소진 시 차단"은 2차 출처의 인용이므로, POC 계정 생성 시 콘솔·이용약관에서
  직접 재확인할 것. 다만 카드 미등록 상태에서 자동 과금이 될 방법은 없으므로,
  사용자 원칙상 최악의 경우(예상 밖 청구)는 발생하지 않는다는 결론은 흔들리지 않는다.

### 1-3. "무료"의 실질 — 일회성이므로 장기 무료가 아니다

- $100은 **월마다 갱신되는 무료량이 아니라 1회성**이다. 매월 무료분이 돌아오지 않는다.
- 미리보기 1회당 수 분(수 초~수십 초)의 샌드박스 실행이면 수백~수천 회는 가능하나,
  결국 소진되고, 그 이후 계속 쓰려면 카드 등록 + Pro($150/월) 또는 사용량 과금이 필요하다.
- 따라서 **E2B Hobby는 POC·평가용 무료이지, 운영용 무료 티어가 아니다.**
  운영에서 샌드박스를 상시로 쓰게 되면 월 $5인 Cloudflare Sandbox가 E2B Pro($150/월)보다
  압도적으로 싸다. 이 점이 "POC만 하고 운영 도입은 보류"라는 결론의 근거다.

## 2. 라이선스 — Apache-2.0, 사용 가능

- GitHub `e2b-dev/E2B` 저장소: **Apache License 2.0** (2026-10-26 직접 확인, ★14,557 —
  근거 문서의 수치와 일치). JS SDK(`e2b`), 코드 인터프리터 SDK(`@e2b/code-interpreter`),
  데스크톱 SDK(`@e2b/desktop`)는 동일 모노레포에서 발행된다.
- MyHub가 E2B SDK를 의존성으로 쓰고 호스티드 클라우드를 API로 호출하는 것은
  라이선스상 제한이 없다 (AGPL 계열이 아니라 코드 복사 금지 사유 없음).
- 참고: 셀프호스팅(Embed 런타임, Terraform, AWS/GCP/Azure)도 같은 저장소에 있으나
  BYOC·온프레미스는 Enterprise 영역이라 MyHub 범위 밖이다.

## 3. Workers 환경 적합성 — 직접 호출 가능 (최근 SDK에서 수정됨)

- **E2B 공식 변경 로그**: "Cloudflare Workers and edge runtime compatibility —
  The JavaScript SDK now imports cleanly under Cloudflare Workers and other edge
  runtimes, removing bare `require` calls that crashed at module load and dropping
  a `new Function` shim rejected by strict content-security policies. (#1583, #1607)"
  → 최신 JS SDK는 **별도 서버 없이 Worker에서 직접 import·호출 가능**하다.
- **호출 경로**: Worker → E2B API (SDK 내부 fetch). API 키는 Worker secret
  (`E2B_API_KEY`)으로 등록. SDK 없이 E2B REST API를 `fetch`로 직접 호출하는
  더 가벼운 경로도 있다 (의존성 0개 — POC에서 검토할 것).
- **주의할 Workers 제약 (실측 전 확정 불가)**:
  - 샌드박스 생성·빌드·실행은 수 초~수 분이 걸릴 수 있다. 단일 Worker 요청의
    CPU 시간 제한(무료 10ms) 안에는 들지 않으므로, 생성은 `fetch` 대기(벽시계)로
    처리하거나 MyHub 기존 Queue(artifact `job-processor.ts`) 경유 비동기 패턴이 필요하다.
    E2B SDK가 내부적으로 WebSocket 스트리밍(PTY 등)을 쓰는 부분은 Workers의
    아웃바운드 WebSocket 지원 범위 안에서만 동작하므로, POC에서
    `Sandbox.create()` + `commands.run()` + `getHost()` 실측으로 확인할 것.
  - 미리보기 URL(`sandbox.getHost(port)`)은 **추측 불가능한 호스트명을 아는 사람
    누구나 접근 가능한 공개 URL**이다 (인증 없음). 단일 사용자 MyHub에서는
    허용 가능한 패턴이나, URL을 D1에 영구 저장·공유하지 않고 미리보기 종료 시
    샌드박스를 kill하는 것이 전제다.

## 4. AI 스튜디오 미리보기용 최소 POC 범위 (코드 작성 전, 설계만)

배경: MyHub의 실제 위험은 "임의 코드 실행"이 아니라 "확인 없는 데이터 변경"이라
`docs/sandbox-options.md`는 도구 실행 경로에는 dry-run + 미리보기 + 명시 승인(③)을
채택했다. 그러나 AI 스튜디오(아티팩트 생성 코드)는 **모델이 만든 코드를 실제로
실행해 보여줘야 하는 첫 표면**이라, E2B가 맞는 자리는 스튜디오 미리보기뿐이다.
도구 실행 경로에는 E2B를 붙이지 않는다.

### POC 단계 (스테이징에서만, 운영 금지)

1. **계정·키**: E2B 계정 생성 (카드 없이) → API 키 발급 → 스테이징 Worker secret
   `E2B_API_KEY` 등록. 크레딧 소진 시 동작을 콘솔·약관에서 직접 재확인 (§1-2 간극 해소).
2. **연결 실측**: 스테이징 Worker에서 최신 `e2b` SDK import →
   `Sandbox.create()` → `commands.run('echo ...')` → `getHost()` 동작 확인.
   실패 시 REST `fetch` 직접 호출로 대체 검토. (SDK 버전·실측 결과 기록)
3. **최소 플로우**: 아티팩트(HTML/JS) 파일을 샌드박스에 쓰고 정적 서버 실행
   (`python3 -m http.server` 등) → `getHost(port)` URL을 iframe 미리보기로 표시 →
   미리보기 종료 시 샌드박스 kill. 빌드(`npm install`)·v2 수정 루프 연결은 POC 범위 밖.
4. **안전 가드**: 샌드박스 생성은 외부 리소스(크레딧) 사용이므로 —
   일일 생성 횟수 상한 + 실패 시 기존 dry-run 미리보기로 폴백 +
   생성·종료·소모량을 감사 로그에 기록. 크레딧 잔액은 콘솔에서 수동 확인
   (E2B API에 잔액 조회 엔드포인트가 있는지 POC에서 확인할 것).
5. **측정·판정 기준**: 미리보기 1회당 크레딧 소모·샌드박스 기동 시간·
   Workers CPU 시간·iframe 로딩 여부를 기록하고, $100 크레딧으로 몇 회 미리보기가
   가능한지 산출. 기존 승인 게이트(명시 승인)는 그대로 유지 — 미리보기는
   게이트를 우회하지 않는다.

### POC 범위 밖 (하지 않을 것)

- 운영 Worker 적용, 운영 D1 쓰기, v2 수정 루프·자동 빌드 파이프라인 연결
- 커스텀 템플릿 빌드, E2B 셀프호스팅, Pro 업그레이드

## 5. Cloudflare Sandbox와 함께 정리한 보류 사유

| 후보 | 상태 | 사유 |
| --- | --- | --- |
| E2B Hobby | **POC만 가능, 운영 도입 보류** | 카드 없이 시작 가능·소진 시 자동 과금 없음(사용 중단)이 확인됐으나, $100이 일회성이라 장기 무료가 아님. 소진 후 계속 쓰려면 카드 + Pro $150/월 필요. |
| Cloudflare Sandbox | **보류 유지** | Workers Paid 플랜($5/월) + Containers 사용량 과금이 필요해 사용자 원칙(카드 없는 무료 티어 고수)과 충돌. 단, 월 $5로 E2B Pro($150/월)보다 훨씬 싸므로, 샌드박스 상시 운영이 필요해지면 E2B보다 먼저 재평가할 것. |

공통: 두 후보 모두 "무료로 영구 운영"이 되지 않는다. MyHub의 도구 실행 경로에는
임의 코드 실행 표면이 없어 dry-run + 미리보기 + 명시 승인이 계속 정답이며,
샌드박스는 AI 스튜디오 미리보기라는 좁은 표면에만 해당한다.

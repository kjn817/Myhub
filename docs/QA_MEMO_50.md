# 메모 50가지 상세 QA 케이스 (49차)

## 생성 (1-15)
1. 기본 메모 생성 (제목+본문)
2. 제목 없이 본문만 생성
3. 본문 없이 제목만 생성
4. 제목·본문 모두 빈 값
5. 매우 긴 제목 (200자)
6. 매우 긴 본문 (10,000자)
7. 한글 입력
8. 영어 입력
9. 이모지 입력 🎉🔥
10. 특수문자 !@#$%^&*()
11. HTML 태그 입력 (<script>alert)
12. 줄바꿈 여러 개
13. 공백만 입력
14. 중복 제목으로 생성
15. 연속 5회 빠른 생성

## 조회 (16-25)
16. 목록 표시
17. 상세 보기
18. 존재하지 않는 ID 조회
19. 새로고침 후 목록 유지
20. 대량 메모 (100개) 목록 로딩
21. 검색: 한글 키워드
22. 검색: 영어 키워드
23. 검색: 특수문자
24. 검색: 결과 없음
25. 검색: 빈 검색어

## 수정 (26-35)
26. 제목 수정
27. 본문 수정
28. 제목을 빈 값으로 수정
29. 존재하지 않는 메모 수정
30. 수정 후 새로고침 반영 확인
31. 긴 본문으로 수정
32. 특수문자로 수정
33. 연속 수정 3회
34. 수정 취소
35. 다른 메모 수정 중 전환

## 삭제 (36-42)
36. 메모 삭제
37. 삭제 확인 다이얼로그
38. 삭제 취소

41. 삭제 후 검색에서 제외
42. 연속 삭제 3개

## 잠금·민감도 (43-50)

44. 잠긴 메모 조회

46. 민감도 설정 (personal)

49. 잠긴 메모 AI 접근 차단 확인
50. 잠금+민감도 동시 설정

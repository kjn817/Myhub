## 근본 원인

에코가 사용하는 Llama 3.3 70B 모델이 메모 도구 마커 형식을 따르지 않음.

**기대 형식:**
```
[MEMO_CREATE]{"text": "내용"}[/MEMO_CREATE]
```

**실제 출력:**
```
MEMO_CREATE 제목='...' 내용='...'
```

마커 브래킷(`[]`) 없이 일반 텍스트로 출력하여 백엔드 파서가 인식하지 못함.

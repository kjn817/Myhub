## 세션 탈취 시나리오 — 확정 사실 (05 문서 전문)

- **세션만으로 가능 (실증)**: 잠긴 메모 본문 읽기 (단건·목록 모두 소유자 복호화로 평문), 잠긴 첨부 복호화 서빙, 본문 덮어쓰기·삭제·재잠금, **암호화 백업 발급** — 백업에는 `auth_pins` 행 (pin_hash·salt·iterations) 이 포함돼 세션 탈취 → 백업 → PIN 오프라인 추측 연쇄가 성립함을 실증. 단 백업 안에서도 잠긴 메모와 Google 토큰은 `ENC:` 그대로였다.
- **세션만으로 불가능 (실증)**: 해제 3경로 전부 PIN 없이는 403, 오답 PIN 403, 무인증·위조 쿠키 401, 검색·MCP·AI 채팅으로는 잠긴 내용 비노출, 평문 백업 운영 403.
- **조건부 (코드 확정·라이브 미실증)**: 탈취 세션이 `method='otp'`면 set-pin으로 PIN 교체 + 완전 탈취 가능, 일상 `pin` 세션은 403. 실제 PIN을 바꿔버리므로 라이브 실증은 의도적으로 하지 않았다.
- 이 항목은 검증·기록이 목적이며 UX 변경은 하지 않았다. 제안 (읽기 step-up, 백업 step-up + auth_pins 백업 제외, 서버 측 페퍼, 패스키, otp 세션 권한 분리) 은 05 문서 §3에 근거와 함께 남겼다.

## PIN·세션 파라미터 — 확정 사실 (05 문서 전문)

- PIN: 숫자 6자리, **PBKDF2-HMAC-SHA-256 100,000회** (GPT 언급과 일치, 코드·운영 D1·백업 행 3중 확인), 솔트 16바이트, 해시 256비트, 상수 시간 비교. 온라인 방어: 5회 실패 → 15분 잠금 (D1 원자 카운터), pin-login IP별 10회/시간·전역 100회/시간. 해시 유출 시 온라인 방어는 무력하다는 오프라인 평가도 기록.
- 세션: HMAC-SHA-256 서명 stateless 토큰, 30일 고정, 쿠키 `HttpOnly; Secure; SameSite=Lax`, 무효화는 session_versions bump (전 토큰 일괄, 개별 무효화 수단 없음), IP/UA 바인딩 없음.

## NOT TESTED (정직하게 남김)

- 라이브에서 올바른 PIN으로 해제 성공: 사용자 PIN을 모르며 추측·추출하지 않았다 (런타임 테스트 PIN으로 성공 실증 완료).
- 수정된 클라이언트의 실제 브라우저 동작: UI-003 버튼 클릭·MEMO-001 렌더러 정지 재발 여부·플레이스홀더 해제·PIN 모달 연동 — 배포는 됐으나 브라우저 QA가 별도로 필요하다.
- 잠긴 **이미지** 첨부의 라이브 왕복 (텍스트 파일로 실증, 이미지 경로는 코드+런타임).
- 파일 해제 (U3) 의 Cloudinary 복호·재업로드 정상 왕복 종단 (게이트·실패 시 잠금 유지까지만 실증).
- fail-closed의 라이브 키 파괴 시험 (운영 키를 깨지 않음 — 런타임으로 실증).
- set-pin 라이브 실증, GPU 오프라인 추측 속도 실측, 로그 실물 대조 (코드 확인까지).

## 잔여·기록 사항

- 잠긴 메모의 태그 (`memo_tags`) 는 평문으로 남는 구조 — 기존 잠긴 4건의 태그 행은 0건이라 현 노출 없음. 2026-10-29 "의도적 유지" 분류를 이번에 임의 변경하지 않았다.
- 단건 GET 응답에 `locked_blocks` 필드가 없어, 블록 복원은 본문 마커가 유일한 경로다 (클라이언트 수정과 정합).
- `unlock-block`의 서버 폴백 (`unlock_pending` 시 복호문 반환 + 암호문 잔류 허용) 은 유지했다 — 클라이언트가 경고를 처리해 재시도·보류를 하게 됐으므로 사용자 오인·고아화는 차단된다. 제거 UPDATE가 반복 실패하면 암호문이 남는 점은 기록해 둔다.
- 트랙 D 라이브 검증 때 생긴 합성 테스트 문자열의 평문 객체 1건이 Cloudinary에 고아로 남았다 (잠금 전 원본, public_id 미기록이라 특정 불가, 내용은 무해한 테스트 문자열). D-1 수정 이후로는 발생하지 않는다.
- 컴포저 (새 메모 작성 화면) 에서의 블록 잠금은 `currentEditingMemoId` 전제상 페인 흐름만 보장된다 — 후속 권고로 기록 (04 문서 §5).

암호화 키 로테이션

새 키로 교체

잠긴 메모·블록·첨부와 Google 토큰을 새 암호화 키로 다시 암호화합니다.
새 키 값은 비밀번호 관리자에서 만든 값을 직접 붙여넣으세요. 값은 이 브라우저에서 서버로 한 번 전송될 뿐, 어디에도 저장되지 않습니다.
실행 후에는 대시보드 시크릿 교체까지 한 번에 마쳐야 합니다 — 교체 전까지 전환된 항목은 읽히지 않습니다.
항목기준 건수dry-run 건수대조
실행 직후 할 일 — 대시보드 시크릿 교체
  1. Cloudflare 대시보드 → Workers & Pages → myhub → Settings → Variables and Secrets
  2. MEMO_ENCRYPTION_KEY를 편집해, 방금 입력한 새 키 값으로 교체하고 Deploy
  3. 교체 후 확인: 메모 화면에서 잠긴 메모 1건을 열어(PIN step-up) 본문이 보이는지, Google 연동 상태가 정상인지 확인
문제가 생기면
  • 건수가 기준과 다르면 실행 버튼이 자동으로 막힙니다. 화면의 건수만 Claude에 알려주세요.
  • 대시보드 교체 후에도 잠긴 메모가 열리지 않으면, 값을 다시 바꾸지 말고 Claude에 알려주세요.
